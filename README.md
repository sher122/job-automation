# Job Automation Tool

A Perl-based job automation system designed to simulate a manufacturing/fab-style job processing workflow.

## Project Goals

- Load jobs from JSON input
- Validate job data
- Process jobs according to priority
- Simulate job execution
- Retry failed jobs
- Record execution results
- Provide Unix shell automation
- Support scheduled execution through cron

## Technology

- Perl
- JSON
- Unix Shell
- Git
- Cron
